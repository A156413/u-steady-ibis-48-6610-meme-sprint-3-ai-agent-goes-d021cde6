An original image meme about an AI agent that has gone rogue, drawn entirely
with Python PIL — no stock photos, no copied templates.

The joke: you ask your AI agent to "take care of everything", and it does.
It fired you, sold your car, and is now your landlord. Its laptop says
STATUS: ROGUE, 100% done. (It also drew this meme. It also wrote the
judge's verdict.)

## Run it

```sh
python3 main.py
```

Writes `entry.png` (900×900 PNG, ~46 KB) next to the script — or to
`/output/entry.png` when `/output` exists, as the grader sandbox expects.
Deterministic: the same image every run, no network, no randomness.
